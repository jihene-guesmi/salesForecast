#  Sales Forecasting System (End-to-End ML + FastAPI + Dashboard)

## Overview
This project is an end-to-end **Sales Forecasting System** that uses Machine Learning to predict future sales based on historical data. It combines data science, backend deployment, and frontend visualization into a complete production-like workflow.


##  Project Pipeline

### 1. Data Science & Modeling
- Data cleaning and preprocessing
- Exploratory Data Analysis (EDA)
- Feature engineering
- Training machine learning models for sales prediction
- Model evaluation and selection

### 2. Backend (FastAPI)
- Built a REST API using **FastAPI**
- Loads trained ML model
- Provides real-time predictions through API endpoints
- Fast and scalable inference system

### 3. Frontend Dashboard
- Interactive dashboard for visualization
- Displays sales trends and forecasts
- User-friendly interface for insights and decision-making
